ПРАВИЛА ПРОВЕРКИ ТЕСТ-КЕЙСОВ
============================

1. СТРУКТУРА ТЕСТ-КЕЙСА
-----------------------
1.1. Название должно быть информативным и отражать суть проверки.
1.2. Название должно начинаться с существительного или глагола в инфинитиве.
1.3. Описание должно содержать цель проверки. Пустое описание — нарушение.
1.4. Предусловия описывают состояние системы ДО теста.
1.5. Постусловия описывают действия после теста.

2. ШАГИ ТЕСТ-КЕЙСА
-------------------
2.1. Каждый шаг содержит ДЕЙСТВИЕ — конкретное и однозначное.
2.2. Каждый шаг содержит ОЖИДАЕМЫЙ РЕЗУЛЬТАТ — проверяемый и конкретный.
2.3. Действие и ожидаемый результат не дублируют друг друга.
2.4. Шаги идут в логической последовательности, нумерация сквозная.
2.5. Каждый шаг атомарный — одно действие.

3. ТЕСТОВЫЕ ДАННЫЕ
-------------------
3.1. Если шаг требует ввода данных — данные должны быть указаны.
3.2. Для позитивных тестов — реалистичные валидные данные.
3.3. Для негативных — заведомо невалидные с указанием причины.

4. ПРАВИЛА РУССКОГО ЯЗЫКА
---------------------------
4.1. Грамотный русский язык, без орфографических и пунктуационных ошибок.
4.2. Официально-деловой стиль, без разговорных выражений и жаргона.
4.3. Единообразное наклонение: инфинитив или повелительное.
4.4. Названия полей и кнопок — в кавычках.
4.5. Без двусмысленности.

5. ПОЛНОТА ПОКРЫТИЯ
--------------------
5.1. Один кейс = один сценарий.
5.2. Кейс воспроизводимый.
5.3. Без условных переходов.
