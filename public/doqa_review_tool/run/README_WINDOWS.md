# Запуск DoQA Review Tool под Windows

## Быстрый старт

### 1. Установка Python

1. Скачайте Python 3.10+ с [официального сайта](https://www.python.org/downloads/windows/)
2. При установке **ОБЯЗАТЕЛЬНО** отметьте галочку **"Add Python to PATH"**
3. Проверьте установку, открыв Command Prompt и выполнив:
   ```cmd
   python --version
   ```

### 2. Первичная настройка

1. Откройте папку `run` в Проводнике
2. Дважды кликните по **`setup.bat`**
3. Скрипт автоматически:
   - Создаст виртуальное окружение
   - Установит все зависимости
   - Создаст файл `.env` из шаблона
   - Откроет `.env` в блокноте для редактирования

### 3. Заполнение .env

В открывшемся файле `.env` заполните обязательные параметры:

**Для режима API (получение кейсов из DoQA):**
```env
DOQA_MODE=api
DOQA_API_TOKEN=ваш_токен_doqa
DOQA_SPACE_ID=123
DOQA_CASE_IDS=456,789,101

AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=sk-ваш_ключ
AI_MODEL=gpt-4o
```

**Для режима файла (из xlsx):**
```env
DOQA_MODE=file
DOQA_FILE=export.xlsx

AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=sk-ваш_ключ
AI_MODEL=gpt-4o
```

Сохраните файл и закройте блокнот.

### 4. Запуск утилиты

Дважды кликните по **`run.bat`**

Утилита:
1. Загрузит тест-кейсы из указанного источника
2. Отправит каждый кейс в ИИ для ревью
3. Сохранит результаты в папку `review_results`

## Структура папки run

```
run/
├── setup.bat                        # Первичная настройка (запустить один раз)
├── run.bat                          # Запуск утилиты
├── doqa_review.py                   # Основной скрипт
├── .env.example                     # Шаблон конфигурации

├── prompt.txt                       # Промт для ИИ (редактируемый)
├── DoQA_test_case_review_rules_.txt # Правила проверки
├── requirements.txt                 # Зависимости Python
├── README_WINDOWS.md                # Эта инструкция
├── venv/                            # Виртуальное окружение (создаётся setup.bat)
└── review_results/                  # Результаты ревью (создаётся автоматически)
```

## Решение проблем

### Python не найден

**Проблема:** `python` не распознаётся как команда

**Решение:**
1. Переустановите Python с отметкой "Add Python to PATH"
2. Или добавьте Python в PATH вручную:
   - Панель управления → Система → Дополнительные параметры системы
   - Вкладка "Дополнительно" → "Переменные среды"
   - В "Path" добавьте: `C:\Users\ВашеИмя\AppData\Local\Programs\Python\Python310\`

### Ошибка установки зависимостей

**Проблема:** `pip install` выдаёт ошибки

**Решение:**
```cmd
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### Кракозябры в консоли

**Проблема:** Русский текст отображается некорректно

**Решение:** В `.bat` файлах уже есть команда `chcp 65001`. Если не помогает:
- Используйте PowerShell вместо Command Prompt
- Или выполните `chcp 65001` вручную перед запуском

### Файл .env не найден

**Проблема:** Утилита не видит `.env`

**Решение:**
1. Убедитесь, что файл называется именно `.env` (не `.env.txt`)
2. В Проводнике включите показ расширений файлов: Вид → Расширения имён файлов
3. Если файл называется `.env.txt`, переименуйте его в `.env`

### Виртуальное окружение не активируется

**Проблема:** Ошибка при выполнении `venv\Scripts\activate.bat`

**Решение:**
```cmd
:: Удалите старое окружение
rmdir /s venv

:: Создайте заново
python -m venv venv

:: Активируйте
venv\Scripts\activate.bat
```

### Ошибка подключения к ИИ

**Проблема:** `ОШИБКА: Не удалось подключиться к ...`

**Решение:**
1. Проверьте `AI_BASE_URL` в `.env`
2. Проверьте интернет-соединение
3. Для Qwen3.8 убедитесь, что заменили `{WorkspaceId}` на реальный ID
4. Проверьте `AI_API_KEY` — должен быть действительным

### Пустой ответ от ИИ

**Проблема:** `ОШИБКА: Пустой контент в ответе ИИ`

**Решение:**
- Для Qwen3.8 это нормально — модель использует режим thinking
- Утилита автоматически извлекает ответ из `reasoning_content`
- Если проблема сохраняется, попробуйте другую модель (например, `gpt-4o`)

## Ручная установка (без setup.bat)

Если `setup.bat` не работает, выполните вручную:

```cmd
:: 1. Откройте Command Prompt в папке run
cd C:\путь\к\run

:: 2. Создайте виртуальное окружение
python -m venv venv

:: 3. Активируйте его
venv\Scripts\activate

:: 4. Установите зависимости
pip install -r requirements.txt

:: 5. Создайте .env
copy .env.example .env
notepad .env

:: 6. Запустите утилиту
python doqa_review.py
```

## Запуск в PyCharm

1. Откройте папку `run` в PyCharm как проект
2. **File → Settings → Project → Python Interpreter**
3. Нажмите шестерёнку → **Add → Existing environment**
4. Укажите: `C:\путь\к\run\venv\Scripts\python.exe`
5. Создайте конфигурацию запуска:
   - **Run → Edit Configurations → + → Python**
   - Script: `doqa_review.py`
   - Working directory: путь к папке `run`
6. Запустите: **Shift+F10**

## Дополнительные .bat файлы

Можно создать дополнительные `.bat` файлы для разных сценариев:

**run_api.bat** — запуск в режиме API:
```batch
@echo off
chcp 65001 >nul
call venv\Scripts\activate.bat
set DOQA_MODE=api
python doqa_review.py
pause
```

**run_file.bat** — запуск в режиме файла:
```batch
@echo off
chcp 65001 >nul
call venv\Scripts\activate.bat
set DOQA_MODE=file
python doqa_review.py
pause
```

## Поддержка

Если возникли проблемы:
1. Проверьте, что Python установлен и добавлен в PATH
2. Убедитесь, что виртуальное окружение создано и активировано
3. Проверьте содержимое `.env` — все обязательные параметры заполнены
4. Проверьте интернет-соединение
5. Посмотрите полный текст ошибки в консоли
